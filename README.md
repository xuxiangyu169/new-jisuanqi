# 华鲲大模型算力集群盈亏平衡计算器 (v2.4.5)

这是一个针对人工智能算力中心（GPU/NPU 服务器集群）在商业运营场景下的盈亏平衡分析与大厂官方 API 获客防线对标的商业精算决策大屏。

---

## 🚀 核心测算维度
1. **物理设施与 CapEx**：包含服务器数量、单价、配套高速组网、存储选配以及折旧年限测算。
2. **物理运营与 OPEX**：基于设备功耗、PUE 能效比、地方工业电费、机柜托管、带宽租赁及运维分摊进行多层次测算。
3. **政策与资金补贴**：包含政府设备建补（冲抵 CapEx）、运营直补（冲抵 OPEX）、运营商电费和带宽折扣。
4. **算力性能极限 (PD分离部署)**：支持阿姆达尔混合吞吐与服务的 Prefill/Decoding 物理分离部署效率增益折算。
5. **多模型子集群混合部署**：重构为动态集群管理模式，支持主集群 A（自动分摊剩余节点）和无限添加的混合子集群，支持对每个子集群单独设定模型预设、独立售价、输入占比与命中率，按产能占比在商业大引擎中进行加权混合均价结算。

---

## 🛠️ 技术栈
* **结构层**：语义化 HTML5 扁平卡片布局。
* **样式层**：现代 CSS3 + Glassmorphic 玻璃微光质感 + Neumorphism 扁平立体阴影。
* **图标库**：Lucide Icons 现代矢量图标。
* **数学内核**：KaTeX 提供公式的动态代入渲染与公式专属名词 hover Tooltip 精准提示。
* **图表库**：ECharts 5.x 绘制多维交互的盈亏平衡点与价格优势区间对比曲线。

## 💻 本地运行与开发修改

### 1. 本地直接运行 (极其简单)
因为本项目是纯前端单页面应用 (SPA)，没有任何复杂的后端框架或数据库依赖：
* **方法一**：直接在文件夹中**双击打开 `index.html`**，即可使用任何主流浏览器浏览并拖拽交互。
* **方法二 (推荐)**：在项目根目录下，使用轻量静态服务器托管以获得更佳的资源载入性能：
  - **Python 3**：`python -m http.server 8000`
  - **Node.js**：`npx serve .`
  - 或者直接使用 VS Code 的 **Live Server** 插件一键启动。

### 2. 代码如何进行美化和改动
* 本项目的全部样式（CSS）、页面结构（HTML）和商业计算精算内核（JavaScript）都集成在根目录下的 **`index.html`** 中，这最大程度地方便了一键改动。
  - **页面美化与排版样式**：见 `index.html` 中的 `<style>` 标签区。
  - **数据大引擎与交互响应**：见 `index.html` 中的 `<script>` 标签区。
  - **核心计算逻辑**：可搜索并定位 JavaScript 内的 `runFinancialCalculator()` 核心精算函数。
* 修改完成后，请确保将 `index.html` **拷贝并覆盖** 至 `dist/index.html`。

### 3. 如何物理部署上线 (Wrangler Pages)
项目配有 Pages 发布环境，如果您已在本地关联 Cloudflare 账户，可在终端运行：
```bash
npx wrangler pages deploy dist --project-name llm-break-even-calculator
```
这会自动将 `dist` 目录下的最新网页推送到您的 Cloudflare Pages 线上公网主链接。
